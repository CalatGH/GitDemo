## 📊 本地端核心指令金三角
1. `git status`：檢查目前有哪些檔案被修改。
2. `git add .`：把所有變更打包加入暫存區（字體由紅變綠）。
3. `git commit -m "說明"`：正式拍照存檔，記錄歷史演進。
